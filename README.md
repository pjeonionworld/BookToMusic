<div>

## 📖 Overview

우리 삶에서 책과 음악은 각각의 의미를 갖습니다.  
BookToMusic은 두 콘텐츠가 유기적으로 연결될 때
더 깊은 몰입을 만들 수 있다는 생각에서 시작했습니다.

<br>

## ✨ Main Features

### 01. AI 기반 책 · 음악 추천

책의 제목을 기반으로 책 정보를 조회하고,
AI를 활용하여 책의 분위기에 어울리는 음악을 추천합니다.

### 02. Playlist

추천받은 책과 음악을 기록하고 자신만의 플레이리스트를 관리할 수 있고,
플레이리스트 라운지를 통해 다른 사용자와 공유할 수 있습니다.

### 03. Ranking

사용자 활동 데이터를 기반으로
책과 음악에 대한 다양한 랭킹을 제공합니다.
